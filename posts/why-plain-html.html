Why plain HTML?

Because I wanted a website, not a second job.

A personal site is a handful of pages that change a few times a month. It does not need a bundler, a package manager, and three hundred megabytes of dependencies to tell you my name is Ben.

My day job is in a NOC, so I've learned what happens when a system has too many moving parts: eventually one of them moves at 3 a.m. I'd rather my website didn't have any.

Plain HTML loads instantly, doesn't care if JavaScript is turned off, and will still open in a browser twenty years from now, long after this week's framework has been deprecated, forked, and abandoned. Twice. When something breaks, there are only a handful of files to blame.

Write the post. Style it once. Log off.
